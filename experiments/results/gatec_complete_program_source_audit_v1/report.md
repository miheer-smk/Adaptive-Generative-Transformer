## 3. Predetermined complete-program execution

**Feasible using existing abstractions; not an existing public program API.** The complete executor takes a callable controller, passes canonical features and consumes unified logits. A non-learned action-script provider can therefore select a predetermined legal sequence in deterministic mode without a second learned action router or operator/mask/accounting changes. Existing accounting tests supply ScriptedController; canonical replay Path C invokes the real selected-only complete-token macro using a canonical provider. **Masking is not program validation.** If requested action logits target an illegal action, masked argmax can choose another legal action. Existing ±100 scripts test already-legal trajectories; the executor has no requested-program argument and cannot reject an unintended fallback on its own. A separate fail-closed adapter must validate each requested action, assert requested/selected/executed correspondence and reject exhausted or surplus script actions. ### Commit ownership and cloning

build_commit_plan is a pure calculation of all context-bearing bank entries, visited or not; FFN contributes none. Each bank entry derives from terminal h with fixed h0/R and pre-commit context. Prelude contributes its own input-derived entry. s and memory write are calculated once. apply_commit_plan checks state identity, consumed status, token index and all planned cache versions before writes; it marks its supplied working state consumed and returns next state. The default bank plus Prelude yields seven context entries. [src/terminal_commit.py:164-240](</home/iiitn/Desktop/Miheer Projects/AGT/AGT_v3_POC/src/terminal_commit.py:164>), [src/blocks.py:359-373](</home/iiitn/Desktop/Miheer Projects/AGT/AGT_v3_POC/src/blocks.py:359>).

Given identical incoming state, input, h0, R, weights and terminal h, commit has no extra route-history argument to distinguish programs. But equal current class predictions do not establish equal terminal h, s, M or C: current logits see only s; commit updates other state from terminal h/prior context. This is a dependency conclusion, not a new experimental equivalence claim. [src/agt.py:414-440](</home/iiitn/Desktop/Miheer Projects/AGT/AGT_v3_POC/src/agt.py:414>), [src/terminal_commit.py:199-219](</home/iiitn/Desktop/Miheer Projects/AGT/AGT_v3_POC/src/terminal_commit.py:199>), [src/output_head.py:33-43](</home/iiitn/Desktop/Miheer Projects/AGT/AGT_v3_POC/src/output_head.py:33>).
