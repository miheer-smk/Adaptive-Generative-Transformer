# Documentation figures

All assets here are derived presentation. Every result figure has SVG and PNG versions, a caption, exact input hashes, publication revisions, transformations and limitations in [figure_provenance.json](../figure_sources/figure_provenance.json). No measurements, intervals or model activations were generated for these plots.

|Figure|Question and scope|
|---|---|
|`clrs_outcomes`|Did the native head, frozen fits or paired feature intervention meet task gates? Separate development/transfer panels; all exact-array scores zero.|
|`feature_contrasts`|Did the latest pilot improve over control and its own query-independent component? Retained one-sided lower bounds, not two-sided intervals.|
|`receiver_outcome`|Did compatibility acquisition add value on parity? Saturation in both arms, zero primary effect and zero ablation decreases.|
|`gradient_averaging`|Did independent-noise averaging repair a fresh task-loss policy? Retained pooled results; repeated tapes are not independent inputs.|
|`mhc_observed_transfer`|What changed across actual mixers on one captured array? Absolute centered energy and observed transfer, not causal attribution.|
|`feature_terminal_geometry`|How did terminal geometry differ between final trained arms? Descriptive means; no competence or same-weight mechanism claim.|

Four implementation/evidence diagrams are also provided as SVG/PNG: `architecture`, `token_execution`, `evidence_map`, `clrs_pipeline`. Their [editable Mermaid sources and shared graph](../figure_sources/README.md) carry configuration scope. SVG/PNG fallbacks are generated from that graph; Mermaid engine rendering is a separate validation question.
